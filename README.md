# Gym member segments and monthly extras credits

The analysis fits k-means to historical member features, checks the fit on held-out members, and compares the current credit-to-all policy with a segment-based policy under the assignment's finance assumptions.

## Run on macOS

Use Python 3.12 as the project interpreter. Open the extracted `gym_clustering` folder in Cursor. Keep the course-provided `gym_members.csv` beside `clustering_analysis.py`. The file is included in the local project package and is also available in Brightspace.

In a terminal from that folder, run:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python clustering_analysis.py
```

If this folder already has a working `.venv`, activate it and run the final two commands.

## Results

- [analysis_results.md](analysis_results.md) records the model comparison, segment centers, new-member decision, and monthly policy value.
- [outputs/elbow_values.csv](outputs/elbow_values.csv) records training and test spread for every k.
- [outputs/cluster_profiles.csv](outputs/cluster_profiles.csv) records the training centers in original units, segment counts and credit decisions.
- Running the script generates `outputs/elbow_train_test.png` and `outputs/member_assignments.csv`. Use the chart generated by your own local run. The assignment file shows each member's segment, credit eligibility, and modeled monthly net under both policies.

## Reproducibility

The analysis uses a seeded random split and fits the scaler and all k-means models on training members. The training elbow determines the number of segments. Training member-level net determines credit eligibility. The test curve uses the fitted centers, and the assignment's offer comparison applies the fixed policies to every member.

For the GitHub repository, upload the script, README, requirements, report, and aggregate result CSVs. Follow course sharing rules for the input CSV and the member-level assignment file. Readers can use their course copy of the data to reproduce the results.
